## 📖 About The Project

**ABT Foundation** (A Better Tomorrow Foundation) is a Rwandan non-governmental organization dedicated to restoring hope and rebuilding futures for vulnerable street children and families. Through counseling, social integration, and sustainable community projects, ABT Foundation works to create lasting positive change.

This repository contains the **official website** of the ABT Foundation — a modern, responsive web application built to raise awareness, share the foundation's mission, and connect with donors and volunteers worldwide.

> *"We believe every child deserves a tomorrow worth looking forward to."*

---

## ✨ Key Features

- 🏠 **Home Page** — Inspiring hero section with the foundation's vision and call-to-action
- 🎯 **Mission & Vision** — Clear presentation of goals and long-term impact
- 📋 **Programs** — Detailed overview of the foundation's initiatives (Isanamitima counseling, social reintegration, livelihood projects)
- 👥 **About Us** — Team profiles and organizational background
- 📸 **Gallery** — Visual storytelling of the foundation's work in the community
- 📞 **Contact** — Easy ways for partners, donors, and volunteers to reach out
- 📱 **Fully Responsive** — Optimized for mobile, tablet, and desktop

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Git](https://git-scm.com/)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/abt-foundation.git

# 2. Navigate into the project directory
cd abt-foundation

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The app will be running at **http://localhost:5173** 🎉

### Build for Production

```bash
# Create an optimized production build
npm run build

# Preview the production build locally
npm run preview
```

## 🌍 Deployment

This project is deployed on **[Vercel](https://vercel.com)** with automatic deployments on every push to the `main` branch.

**Live URL:** [https://a-better-tomorrow-foundation-org.vercel.app/](https://a-better-tomorrow-foundation-org.vercel.app/)

To deploy your own fork:

1. Push the repository to GitHub
2. Import the project on [vercel.com](https://vercel.com)
3. Vercel auto-detects Vite — click **Deploy**
4. Your site is live in seconds ✅
